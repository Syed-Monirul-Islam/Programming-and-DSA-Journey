## 📚 Learning Roadmap & Topics Covered

### 🔹 Semester 1: C & C++ Fundamentals

#### 1. Introduction To Programming (`C Language`)
* **Core Concepts:** Variables, Data Types, Operators, Conditional Logic (`if-else`, nested conditions)
* **Control Flow:** Loops (`for`, `while`), Nested Loops, Pattern Printing
* **Memory & Storage:** Arrays, Array Operations, Dynamic Memory Allocation
* **Text Processing:** Character Arrays, String Operations
* **Modular Programming:** Functions, Pointers, and Recursion
* **Problem Solving:** Basic math, loops, array/string manipulations on online judges

#### 2. Introduction To C++ (`C++ for DSA`)
* **Language Basics:** C++ Syntax, Standard I/O, Built-in Utility Functions (`min`, `max`, `swap`)
* **Memory Management:** Dynamic Memory Allocation (`new`, `delete`)
* **Standard Strings:** C++ `std::string` class & stream manipulation
* **Object-Oriented Programming:** Classes and Objects, Constructors, Array of Objects

---

### 🔹 Semester 2: Data Structures & Algorithms

#### 3. Basic Data Structures
* **Complexity Analysis:** Time Complexity & Space Complexity (Asymptotic Notations)
* **Searching & Sorting:** Linear Search, Binary Search, Selection Sort
* **Pointers & Ranges:** Two Pointers Technique & Prefix Sum
* **Linked Lists:** Singly Linked List, Doubly Linked List (Insert, Delete, Reverse operations)
* **Linear Structures:** Stack Implementation, Queue Implementation
* **Trees & Heaps:** Binary Tree Traversals, Binary Search Tree (BST), Priority Queue & Heap
* **C++ STL:** Standard Template Library (`vector`, `list`, `stack`, `queue`, `priority_queue`, `map`, `set`, `pair`)

#### 4. Introduction To Algorithms
* **Graph Traversal:** Graph Representations (Adjacency Matrix & List), BFS, DFS, and 2D Grid Traversals
* **Shortest Path Algorithms:**
  * Dijkstra's Algorithm (Single-source shortest path)
  * Bellman-Ford Algorithm (Negative weight cycle detection)
  * Floyd-Warshall Algorithm (All-pairs shortest path)
* **Disjoint Set Union (DSU):** Path Compression, Union by Size, Cycle Detection in Undirected Graphs
* **Spanning Trees:** Minimum Spanning Tree (MST)
* **Dynamic Programming (DP):**
  * Memoization & Tabulation
  * 0-1 Knapsack and its variations
  * Unbounded Knapsack
  * Longest Common Subsequence (LCS) and its variations
